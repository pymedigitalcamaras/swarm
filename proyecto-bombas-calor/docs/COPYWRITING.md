## 🎯 Principios Aplicados

- **Claridad sobre creatividad:** Texto que el instalador entienda en 3 segundos
- **Beneficios sobre características:** No decimos "COP 4.2", decimos "Ahorra 70% en gas"
- **Voz latinoamericana:** Cercana, profesional, sin tecnicismos innecesarios
- **CTAs específicos:** No "Click aquí", sino "Ver precios de distribuidor"

### Configurador de Proyecto (/herramientas/configurador-proyecto)

**Título:**
> Configura el proyecto perfecto

**Subtítulo:**
> Responde 5 preguntas y te recomendamos la bomba de calor ideal, con especificaciones técnicas y precio de distribuidor.

**Pasos:**
1. Tipo de proyecto (Casa nueva / Remodelación / Reemplazo)
2. Metros cuadrados
3. Zona climática (templada / fría / muy fría)
4. Uso (Solo calefacción / Calefacción + ACS / Todo)
5. Tipo de emisor (Radiadores / Suelo radiante / Fan-coils)

**Resultado:**
> Recomendación de producto + Ficha técnica + Precio (si logueado)

> Cotizar este proyecto →
